# P3 Golden Profile

The golden manifest (`golden-manifest.json`) is the expected result of capturing
the P3 fixture. It is produced by `scripts/profile/validate_p3.py --update-golden`
which applies `schema.sql` + `seed.sql` to a fresh PostgreSQL 16 container,
captures the profile, and writes the golden.

## Current status: golden pending first CI establishment

The golden manifest is established by the first successful CI run of
`validate_p3.py --update-golden`. Once produced, it should be committed and
CI switched to verify-only mode (remove `--update-golden`).

## Validation checks (run by `validate_p3.py`)

1. **Self-consistent:** stored fingerprint == recomputed fingerprint (both builds).
2. **Deterministic:** two captures produce identical fingerprint.
3. **Golden:** captures == committed `golden-manifest.json` (or establishes it with `--update-golden`).
4. **Secret-scan clean:** 12 patterns covering IPs, emails, tokens, credentials, JWTs, connection strings, private keys. Scans `schema.sql`, `seed.sql`, `golden-manifest.json`, and both captured manifests.

## Byte-determinism

`generate_p3.py` is byte-deterministic: identical P1 input produces identical
`schema.sql` and `seed.sql` bytes (no embedded timestamps).
